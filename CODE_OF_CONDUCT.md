# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report behaviour that breaks it through GitHub's private reporting
([Security → Report a vulnerability](https://github.com/JoHoenk/teachers-teammate/security/advisories/new)),
or open an issue if nothing private is involved. The maintainer decides what follows.
