# Security

Report a vulnerability privately: **Security → Report a vulnerability** on the
[repository page](https://github.com/JoHoenk/teachers-teammate/security/advisories/new). Please do
not open a public issue for it.

Only the latest release gets fixes.

A download from anywhere but the [releases page](https://github.com/JoHoenk/teachers-teammate/releases)
is not ours; how to check one is in the
[code signing policy](docs/code_signing_policy.md).
